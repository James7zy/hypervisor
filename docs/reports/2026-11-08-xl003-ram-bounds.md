## 交付与根因

旧建表忽略 `mem_base/mem_size`，将 PA 截到 1 GiB 边界并映射整个 1 GiB。
Linux 每 VM 多授权 768 MiB；SVM VM0 还将 EL2 镜像映入可读写 RAM。修复以真实配置
三元组精确建表，保持现有加载地址、设备窗口及 GIC/UART 洞不变。

## 架构评审

- 生产 builder 与 host 共享源，测试使用真实配置；独立 oracle 不依赖生产自检返回值。
- 所有有效叶按 IPA 分类，错误 Device 属性不能掩盖 RAM 越界；检查完整 OA/属性/覆盖。
- 新 ARM 逻辑留在 `arch/arm64/mmu/`，失败仍沿原通道保持 VM OFF。
- 无 loader 地址重排、无旧 expect 放宽、无设备窗口行为改变；未触碰用户脚本。
- 原始文本证据已归档并附 SHA256；验收后收尾只改文档，不改变被测实现。
